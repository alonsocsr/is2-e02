# 📰 Sistema de Gestión de Contenidos - Proyecto Académico

Este proyecto fue desarrollado como parte de una asignatura universitaria en conjunto con un equipo de desarrollo. El objetivo principal fue construir un completo **sistema de gestión de contenidos (CMS)** con funcionalidades avanzadas orientadas a la publicación, control y visualización de contenidos.



## ⚙️ Funcionalidades Principales

- ✅ Publicación y edición de contenidos
- 📌 Tablero **Kanban** para el flujo editorial
- 👤 Gestión de usuarios y roles (admin, autor, moderador, lector, etc.)
- 🕒 Historiales de actividad por usuario y versión de cada publicación
- 📊 Estadísticas de publicaciones: visitas, interacciones, estado
- 💸 Soporte para **categorías de contenido pagas**
- 🖼️ Carga y gestión de imágenes con **Cloudinary**
- 💳 Integración de pagos con **Stripe**
- 🌐 Simulación de entorno de producción con **NGINX en servidor Linux**

---

## 🛠️ Tecnologías Utilizadas
 **Backend y frontend:** Django (Python), JavaScript, TailwindCSS.
 **Base de Datos:** PostgreSQL. 
 **Autenticación:** Django auth + roles  
 **Adicionales:** Stripe para manejar pagos y Cloudinary para alojar contenido multimedia.
